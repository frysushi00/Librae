# Librae 📚

**An all-in-one AI-powered book detection, text extraction, and recommendation app for Android.**

Librae makes discovering your next favorite book easier. Simply point your camera at a book cover, and Librae uses machine learning and computer vision to detect the book, extract its title and author, and recommend similar books based on their content.

## ✨ Features

- **Real-Time Book Detection** — Uses **YOLOv11** to detect and localize book covers directly from the camera feed.
- **Text Extraction with OCR** — Applies Optical Character Recognition (OCR) to extract book titles and author names from detected covers.
- **Intelligent Book Recommendations** — Uses a **Content-Based Filtering (CBF)** recommendation system to suggest relevant books based on the scanned book's content and characteristics.
- **All-in-One Experience** — Combines computer vision, text recognition, and recommendation algorithms in a single Android application.

## 🛠️ Technologies

- **YOLOv11** — Book cover detection
- **Optical Character Recognition (OCR)** — Book title and author extraction
- **Content-Based Filtering (CBF)** — Book recommendation
- **Android** — Mobile application platform

## 📲 Installation

Follow these steps to install Librae on your Android device:

1. **Download the APK** — Get [`Librae-v3.apk`](https://github.com/frysushi00/Librae/blob/main/Librae-v3.apk) from the repository.
2. **Locate the file** — Open your device's Downloads folder and find the downloaded APK.
3. **Install the application** — Tap the APK file and follow the installation instructions.
4. **Allow installation if prompted** — Depending on your Android version and settings, you may need to authorize installation from that source.
5. **Launch Librae** — Open the app and start discovering books.

> **Note:** Only install APK files from sources you trust. Android may display a security warning when installing applications outside the Play Store.

## 🚀 How It Works

1. **Scan** — Point your camera at a book cover.
2. **Detect** — YOLOv11 identifies the book cover in the camera frame.
3. **Extract** — OCR reads the title and author from the detected cover.
4. **Recommend** — The CBF recommendation system suggests relevant books based on the scanned book.
5. **Discover** — Explore recommendations and find your next read.
